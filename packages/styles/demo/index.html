Massachusetts Design System

Reusable CSS

A collection of CSS classes based on MDS design tokens and common patterns. These utility and helper classes can be used to build components and layouts with consistent styling across the state of Massachusetts web ecosystem.

Helpers

Reusable structural classes for page layout and shared patterns.

Layout

Reference examples for structural classes such as .mds-body and .mds-section-container.

Grid

Responsive column and gutter examples for the .mds-grid grid layout.

Utilities

Single-purpose composable styles, built on design tokens.

Typography

Heading, body, label, caption, and eyebrow utilities with responsive examples.

Spacing

Spacing scale, directional margin and padding utilities, plus box-model examples.

Radius

Semantic border-radius utilities shown on simple component cards.

Shadow

Container, modal, and hover shadow utilities using semantic elevation tokens.

Colors

A visual reference for the generated background, text/icon, and overlay color utilities.

Grid Span

Numeric span utilities and the current legacy column alias examples.
