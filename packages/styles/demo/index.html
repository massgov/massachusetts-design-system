Massachusetts Design System

Reusable CSS

A collection of reusable CSS classes generated from MDS design tokens. These utility and helper classes can be used to build components and layouts with consistent styling across products.

Utilities

Single-purpose composable styles, built on design tokens and exposed as a CSS class. Following the tokenized naming convention for class names.

Typography

Heading, body, label, caption, and eyebrow utilities with responsive examples.

Spacing

Spacing scale, directional margin and padding utilities, plus box-model examples.

Radius

Semantic border-radius utilities shown on simple component cards.

Shadow

Container, modal, and hover shadow utilities using semantic elevation tokens.

Colors

A visual reference for the generated background, text/icon, and overlay color utilities.

Grid Span

Numeric span utilities and the current legacy column alias examples.
