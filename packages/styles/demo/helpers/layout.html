Layout Helpers

Structural classes for page-level defaults and centered content.

.mds-body

Apply the .mds-body helper class to the <body> element for the baseline surface, text color, type style, and zero browser margin. 

<body class="mds-body"></body>

The container class keeps content centered on the page, caps the page max width, and applies responsive inline padding from breakpoint tokens.
