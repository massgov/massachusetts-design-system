Font shorthand utilities generated directly from the semantic text tokens, including breakpoint-responsive heading and body sizes.

Recommended font style to use with H2 headings

.mds-text-heading-lg (scales with breakpoints)

.mds-text-body-lg-bold (scales with breakpoints)

Emphasized large body copy is useful for page intros, summaries, and prominent supporting text.

.mds-text-body-lg (scales with breakpoints)

Large body copy is useful for page intros, summaries, and prominent supporting text.

.mds-text-body-bold

Body text that are emphasized for primary content.

.mds-text-body

.mds-text-caption

Caption text works well for secondary metadata and support notes for images, charts, videos, and other visual elements.
