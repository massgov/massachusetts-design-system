## Code

The footer uses Action Link for contact and navigation links, and Icon Button for
social links. Their styles are bundled into `footer.css`, so no separate
component stylesheets are needed for the footer.

The CSS tab shows the complete compiled footer stylesheet. Load the semantic token
stylesheet separately, as shown in the Imports tab. If you already load
`@massds/mds-components/index.css`, it already includes the footer styles.
