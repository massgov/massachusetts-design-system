## Code

The footer uses Action Link for contact and navigation links, and Icon Button for
social links. Load `action-link.css` and `icon-button.css` before `footer.css`;
`footer.css` alone does not include these component styles.

The CSS tab includes all three stylesheets in that order. Load the semantic token
stylesheet separately, as shown in the Imports tab. If you already load
`@massds/mds-components/index.css`, it includes all three component stylesheets.
