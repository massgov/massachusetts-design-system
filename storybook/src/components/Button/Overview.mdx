# Button overview

A button helps people take an action, such as submitting information, saving changes, starting a process, or confirming a decision.

Use a button when the person needs to do something on the current page or within the current workflow. The button label should clearly describe the action so people understand what will happen when they select it.

<ButtonExample text="Button" />

## Variants

### Color

Set the `color` property to `Primary`, `Secondary`, `White`, or `Danger` to change the button's color.

### Type

Set the `type` property to change the button's appearance. Available types include `Fill`, `Outline`, and `Ghost`.

> - Use the lowest-emphasis button variant that clearly communicates the importance of the action
> - Use only one filled button within an action group whenever possible
> - Use outline and ghost buttons for supporting actions
> - Reserve danger buttons for irreversible actions

Set the `type` property to `Fill` to draw filled buttons.

### Size

Use the `size` property to change the button's size. Most buttons use `MD`. `LG` is available for certain uses, like a Hamburger Menu button or a featured call to action in a hero area.

<div className="mds-docs-example-row mds-gap-md">
  <ButtonExample text="MD" size="MD" />
  <ButtonExample text="LG" size="LG" />
</div>

### With icons

Use icons only when they add helpful context or make an action easier to recognize.

#### Use a left icon when the icon identifies the action

Place an icon before the label when the icon helps people quickly recognize the type of action they are taking. Left icons work well for actions that are commonly associated with a specific symbol, object, or tool.

Examples:

<div className="mds-docs-example-row mds-gap-sm">
  <ButtonExample text="Download" leftIcon="download-simple" />
  <ButtonExample text="Previous" type="Outline" leftIcon="arrow-left" />
  <ButtonExample text="Log in" type="Ghost" leftIcon="user" />
</div>

#### Use a right icon when the action moves someone forward

Place an icon after the label when the icon suggests progression, continuation, or movement to another step or destination. Right icons work well for actions that move someone forward in a process or indicate that something will happen after activation.

Examples:

<div className="mds-docs-example-row mds-gap-sm">
  <ButtonExample text="Next" rightIcon="arrow-right" />
  <ButtonExample text="Start application" type="Outline" rightIcon="arrow-right" />
  <ButtonExample text="Check eligibility" type="Ghost" rightIcon="arrow-right" />
</div>

### Disabled

To disable a button, add the `disabled` property. A disabled button shows that an action is currently unavailable and cannot be selected or activated. They should be used only when the action will become available after the user completes a required step or meets a specific condition.

<div className="mds-docs-example-row mds-gap-md">
  <ButtonExample text="Fill" disabled />
  <ButtonExample text="Outline" type="Outline" disabled />
  <ButtonExample text="Ghost" type="Ghost" disabled />
</div>
