# Utility Navigation overview

The utility navigation component provides a compact action bar for high-priority utility actions that sit above or alongside primary navigation.

Use it when people need quick access to global actions like opening a menu, changing language, logging in, or returning to the main Mass.gov home experience.

<UtilityNavExample />

---

## Variants

### Default

Use the default variant when the experience needs both a menu trigger and supporting utility actions on the same bar.

<UtilityNavExample />

### Hamburger menu only

Use this variant when the utility bar only needs to expose a primary menu entry point.

<UtilityNavExample actionButtons={[]} />

### Utility buttons only

Use this variant when the surrounding page already provides the main navigation trigger elsewhere.

<UtilityNavExample startVariant="none" />

### Mass.gov home link and utility buttons

Use this variant when the left-side action should return people to the main Mass.gov home destination instead of opening a menu.

<UtilityNavExample startVariant="home-link" />
