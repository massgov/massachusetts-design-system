# Menu overview

A temporary menu that appears when a user selects a button, icon, or other element. It shows actions or options related to what the user selected. The menu disappears when the user chooses an option or interacts elsewhere on the screen.

---

## Variants

### Menu

Menu items adapt dynamically based on user interaction. Ensure high contrast and visible focus indicators across all modes. The available states are `Default`, `Hover`, `Active`, `Focus`, and `Disabled`.
