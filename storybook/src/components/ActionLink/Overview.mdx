# Action link overview

An action link takes people to another destination while giving the link more emphasis than a link within body text.

Use a short label that makes the destination or next step clear. Use a button instead when the interaction changes data or performs an action on the current page.

<ActionLinkExample />

## Variants

### Color

Use `Primary` for the standard treatment and `Neutral` when the link needs less visual emphasis. Use `White` only on a dark background that provides sufficient contrast.

<div className="mds-docs-example-row mds-gap-md">
  <ActionLinkExample text="Primary" color="Primary" />
  <ActionLinkExample text="Neutral" color="Neutral" />
  <span className="mds-docs-example-surface mds-padding-inline-xs mds-padding-block-xs mds-background-section-brand-primary-highest">
    <ActionLinkExample text="White" color="White" />
  </span>
</div>

### Size

Set the `size` property to `Small`, `Medium`, or `Large`. Choose a size that matches the surrounding content hierarchy.

<div className="mds-docs-example-row mds-gap-md">
  <ActionLinkExample text="Small" size="Small" />
  <ActionLinkExample text="Medium" size="Medium" />
  <ActionLinkExample text="Large" size="Large" />
</div>

### Icons

Action links may include an icon before the label, after the label, or on both sides. Use an icon when it clarifies direction or destination; do not add one only for decoration.

<div className="mds-docs-example-row mds-gap-md">
  <ActionLinkExample text="Previous" leftIcon="arrow-left" rightIcon="" />
  <ActionLinkExample text="Continue" rightIcon="arrow-right" />
  <ActionLinkExample text="Browse services" leftIcon="arrow-left" rightIcon="arrow-right" />
</div>

### Icon weight

Set `iconWeight` to `Bold` or `Regular`. The label typography remains the same while the icon weight changes.

<div className="mds-docs-example-row mds-gap-md">
  <ActionLinkExample text="Bold icon" iconWeight="Bold" />
  <ActionLinkExample text="Regular icon" iconWeight="Regular" />
</div>

### Interaction states

Action links provide default, hover, pressed, and keyboard-focus states. Hover and pressed states underline the label, and the focus treatment adapts to light or dark backgrounds.

> Action links do not have a disabled state. Remove an unavailable link until its destination is available.
