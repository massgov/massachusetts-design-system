# Action link overview

An action link helps people navigate to an important destination that needs more visual emphasis than an inline link. It stands on its own outside running text while keeping the behavior and semantics of a link.

## Variants

### Color

Action links are available in `Primary`, `Neutral`, and `White` color treatments. The `White` treatment provides a light link treatment for dark backgrounds.

<div className="mds-docs-example-row mds-gap-md sb-unstyled">
  <ActionLinkExample text="Primary" color="Primary" />
  <ActionLinkExample text="Neutral" color="Neutral" />
  <span className="mds-docs-example-surface mds-padding-inline-xs mds-padding-block-xs mds-background-section-brand-primary-mid">
    <ActionLinkExample text="White" color="White" />
  </span>
</div>

### Size

Action links are available in `Small`, `Medium`, and `Large` sizes.

<div className="mds-docs-example-row mds-gap-md sb-unstyled">
  <ActionLinkExample text="Small" size="Small" />
  <ActionLinkExample text="Medium" size="Medium" />
  <ActionLinkExample text="Large" size="Large" />
</div>

### Icons

Single action links always include an icon before or after the link. When multiple action links are grouped together, the icon is not required, but may be used if it provides helpful context for the user.

Use the `Bold` icon weight for a standalone action link. Use `Regular` when multiple action links appear in a list.

Common single action link icon uses include:

A leading arrow for back navigation.

<div class="sb-unstyled mds-docs-example-frame">
<ActionLinkExample text="Back" leftIcon="arrow-left" rightIcon="" />
</div>

A trailing arrow for forward navigation.

<div class="sb-unstyled mds-docs-example-frame">
<ActionLinkExample text="View required documents" rightIcon="arrow-right" />
</div>

An external-link icon for a destination that opens in a new window.

<div class="sb-unstyled mds-docs-example-frame">
<ActionLinkExample
  text="View your federal tax account on IRS.gov (opens in a new window)"
  rightIcon="arrow-square-out"
/>
</div>

A jump icon for navigation to content on the current page.

<div class="sb-unstyled mds-docs-example-frame">
<ActionLinkExample text="View eligibility requirements" rightIcon="arrow-elbow-right-down" />
</div>
