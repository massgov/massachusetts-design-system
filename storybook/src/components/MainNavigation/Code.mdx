## API

<Controls of={MainNavigationStories.Playground} />

Each item accepts `text`, `href`, `children`, `current`, and `expanded`. Parents with children expand their submenu rather than navigate. Use `current: true` on a destination to mark it with `aria-current="page"` and highlight its parent. `expanded: true` sets the initial open section; only one section opens at a time.

The optional `stackedText` label is used in the vertical layout. Give each navigation instance a unique `id` and a descriptive `ariaLabel`.

## Setup

Render `main-navigation.twig` with the schema-backed component data, then initialize its interactions after inserting the HTML:

```js
import '@massds/mds-components/main-navigation.css';
import { initMainNavigation } from '@massds/mds-components/main-navigation.js';

const cleanup = initMainNavigation(document);
// Call cleanup() before removing the navigation.
```

The initializer supports parent buttons, one open section at a time, desktop hover, Arrow Down to open and focus the first child, and Escape to close and return focus to the parent. Tab follows the visible links and buttons in document order. The component requires JavaScript for these interactions.
