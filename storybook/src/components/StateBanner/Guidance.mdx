# State banner guidance

---

## Content

### Best practices

The state banner establishes trust and authenticity for official Massachusetts government websites.

---

## Design

### Usage

#### When to use

You must use the state banner when:

- Your site will be hosted as a subdomain of mass.gov, for example: yourname.mass.gov

#### When not to use

Do not use the state banner when:

- Your site is hosted on a domain that does not use mass.gov

#### Responsive behavior

The state banner changes visual display based on the design system breakpoints including font size, line height, and spacing with a max width of 1440px. This ensures that the minimum height possible is used for the smallest supported screen width at 320px, and the left alignment follows the Design System grids.

## Accessibility

### Mouse control

- Single click on the dropdown toggles expand/collapse
- Use a pointer cursor over the dropdown link

### Touch control

- Single tap on dropdown toggles expand/collapse
- Includes visual feedback when tapped

### Keyboard control

- Dropdown can receive focus via Tab key
- Enter/Space activation: Enter or Space key toggles dropdown when focused
- Escape key closes the expanded dropdown if open

### Assistive technology

- Include proper ARIA roles for the dropdown
- Announce current state of dropdown (expanded/collapsed)
- Include alternative text for brand seal image description
- Screen readers can access all content when expanded
