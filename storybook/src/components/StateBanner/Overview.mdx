# State Banner

The Massachusetts state website banner serves as a consistent, recognizable element across all Mass.gov digital properties to let users know they are on an official state website. It should appear at the top of each page within all Mass.gov sites.

## Usage

### When To Use
- At the top of all Mass.gov web pages

### When Not To Use
- State related apps or websites that do not have the Mass.gov extension
