# State banner overview

The state banner serves as a consistent, recognizable element across digital properties to let users know they are on an official state site. It must appear at the top of each page within all Mass.gov, Massachusetts.gov, Ma.gov, and State.ma.us sites, including their subdomains (e.g. example.mass.gov).

## Variants

### Color

The state banner uses one standardized color treatment to create a single, consistent trust pattern across official Commonwealth digital experiences. This helps constituents quickly recognize that they are on an official government website, regardless of which agency or organization produced the experience.
