# Semantic heading overview

Semantic headings organize content into sections and help people understand the structure of a page. They make content easier to scan and allow people using assistive technology to navigate between sections.

You can change a heading's font size or weight to fit your design, but these changes should be applied consistently across the UI to maintain a clear visual hierarchy.

---

## Variants

### Mass.gov

The `Mass.gov` variant uses the Mass.gov heading treatment, including a decorative underline for H2 headings. It provides an additional visual distinction between sections.

### Plain

The `Plain` variant uses heading typography without the Mass.gov decorative treatment. It provides a simpler visual presentation while preserving the same semantic heading structure. A common use case for the `Plain` styling is complex forms.
