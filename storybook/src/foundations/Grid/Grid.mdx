# Grid

The Massachusetts Design System uses a responsive grid to organize content and create consistent layouts across different screen sizes. The grid provides a flexible structure for aligning elements, managing column widths, and adapting layouts to different devices.

---

## Grid structure

The grid is made up of columns and gutters that provide a consistent structure for positioning content.

- **Columns:** Vertical divisions used to determine the width and placement of content.
- **Gutters:** Spaces between columns that help separate content and maintain consistent alignment.
- **Grid container:** The area that holds the columns and establishes the layout structure.

### Grid wrapper

Use `.mds-grid`, usually within `.mds-section-container`, to create a responsive grid layout for grid-based patterns. The section container centers content, limits its width to 1280px, and supplies responsive horizontal padding.

## Breakpoint syntax

Add a breakpoint prefix before a grid span utility to change the span at that breakpoint and below. For example, `md:mds-grid-span-6` applies at viewport widths of 768px and below.

<div className="mds-docs-reference-table-scroll">
  <table className="mds-docs-reference-table">
    <thead>
      <tr><th scope="col">Prefix</th><th scope="col">Media query</th><th scope="col">Total columns</th></tr>
    </thead>
    <tbody>
      <tr><td><code>xl:</code></td><td><code>@media (max-width: 1280px)</code></td><td>12</td></tr>
      <tr><td><code>lg:</code></td><td><code>@media (max-width: 1024px)</code></td><td>12</td></tr>
      <tr><td><code>md:</code></td><td><code>@media (max-width: 768px)</code></td><td>6</td></tr>
      <tr><td><code>sm:</code></td><td><code>@media (max-width: 480px)</code></td><td>6</td></tr>
      <tr><td><code>xs:</code></td><td><code>@media (max-width: 320px)</code></td><td>6</td></tr>
    </tbody>
  </table>
</div>

When multiple prefixed spans apply, the smaller breakpoint takes precedence regardless of class order in the markup.

> At **md breakpoint**, the total columns of the .mds-grid changes from **12** to **6**. `.mds-grid-span-6` is the max column span, and will be displayed at full width. Column spans should not exceed total columns spans at all breakpoints.

## Responsive grid utilities

Combine multiple breakpoint prefixes with `.mds-grid-span-*` to create a responsive grid layout that changes across breakpoints.

In this example, the grid items will be 6 columns wide by default, 4 columns wide at the lg breakpoint and below, 3 columns wide at the md breakpoint and below, and full width at the sm breakpoint and below. Resize the viewport to see the layout change.

- `.mds-grid-span-2`: 12 / 2 = **6 items per row** above 1024px.
- `lg:mds-grid-span-3`: 12 / 3 = **4 items per row** from 769px to 1024px.
- `md:mds-grid-span-2`: 6 / 2 = **3 items per row** from 481px to 768px.
- `sm:mds-grid-span-6`: 6 / 6 = **1 item per row** at 480px and below.
