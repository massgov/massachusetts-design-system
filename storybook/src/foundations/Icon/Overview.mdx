# Icon

Icons are visual symbols that help people quickly understand actions, content, status, or navigation. 

Use icons when they add clarity or help reinforce nearby text. Do not rely on icons alone to communicate important information, especially when the meaning may not be universally understood. For example, it's common to only use a social media icon. They're easy to recognize and understand.

[Learn more about the Design System icon library](https://www.mass.gov/info-details/iconography).
